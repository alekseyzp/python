# Knife Details — сборка фиксированного раскладчика

Это отдельная рабочая папка `knife-details/` в ранее пустом репозитории. Она не меняет исходники сайта knifedetails.com и ничего не публикует автоматически.

## Что собирается
Реальный Rust/WebAssembly движок проекта [Nestbolt](https://github.com/skulitom/Nestbolt), производный от Sparrow/jagua-rs. Исходники фиксируются конкретным SHA. Компиляция выполняется в GitHub Actions и результат помещается в артефакт `Knife_Details_FixedSheet_Timeweb.zip`. В статической сборке все вычисления выполняются локально в браузере.

## Заводские значения Knife Details
- Лист 900 × 600 мм (можно изменить)
- Поля со всех сторон 5 мм
- Минимальный зазор между бланками 3 мм
- Произвольные углы и зеркалирование для импортированных моделей
- DXF/SVG, включая поддерживаемые библиотекой отверстия и кривые

**Внимание:** текущая версия использует интерфейс Nestbolt; перенос интерфейса Sparrow Studio, ручная раскладка с R / Shift+R, учёт стальных листов и продолжение от ранее вырезанных деталей остаются отдельными задачами. Нельзя заявлять поддержку любого DXF-объекта и производственную пригодность без проверок в CAM.

### Запуск
GitHub → Actions → «Build Knife Details WASM» → последний запуск → Artifacts. ZIP распаковать на временном адресе `/nesting-test/` обычного Timeweb. Не заменять рабочую `/nesting/` без испытаний.

Сохраняются исходные [лицензия MIT Nestbolt](https://github.com/skulitom/Nestbolt/blob/main/LICENSE) и `THIRD_PARTY_NOTICES`.

Проверки: `knife-details/customize.py` — строгие замены исходных настроек; `knife-details/verify_dist.py` — присутствие истинного WebAssembly и ссылок на собранные ресурсы.
